#  Лабораторна робота №1  
## **Проєктування бази даних для системи оцінювання книг**

---

## **Мета роботи**
Побудувати ER-модель бази даних для системи **Book Rating System**, яка дозволяє користувачам оцінювати, коментувати та переглядати книги.

---

## **1. Основна ідея**

**Book Rating System** — веб-застосунок, який буде дозволяти користувачам:
- створювати профілі;
- переглядати каталог книг;
- залишати оцінки (1–5 зірок);
- писати текстові відгуки;
- переглядати середній рейтинг;
- шукати книги за автором, жанром або видавництвом.

**Зацікавлені сторони:**
- **Користувачі (Users)** — оцінюють і коментують книги.  
- **Адміністратор** — керує базою книг, авторів, жанрів, видавництв.  
- **Система** — розраховує середній рейтинг і забезпечує збереження даних.

---

## **2. Сутності бази даних**

### **Users (Користувачі)**

| Поле | Тип | Опис |
|------|------|------|
| `UserID` | PK, SERIAL | Унікальний ідентифікатор користувача |
| `Username` | VARCHAR(50) | Ім’я користувача (унікальне) |
| `Email` | VARCHAR(100) | Електронна пошта (унікальна) |
| `Password` | VARCHAR(255) | Хеш пароля |
| `Nickname` | VARCHAR(50) | Псевдонім (опціонально) |
| `AvatarURL` | VARCHAR(255) | Посилання на аватар користувача |

**Примітка:**
- Email і Username унікальні.  
- При видаленні користувача видаляються його оцінки та відгуки (`ON DELETE CASCADE`).  
- Аватар зберігається як **URL-шлях**, не як файл.

---

### **Book (Книга)**

| Поле | Тип | Опис |
|------|------|------|
| `BookID` | PK, SERIAL | Унікальний ідентифікатор книги |
| `Title` | VARCHAR(255) | Назва книги |
| `ISBN` | VARCHAR(17) | Міжнародний стандартний номер книги |
| `PublicationDate` | DATE | Дата публікації |
| `Description` | TEXT | Короткий опис книги |
| `PageCount` | INTEGER | Кількість сторінок |
| `Language` | VARCHAR(50) | Мова книги |
| `CoverImageURL` | VARCHAR(255) | Обкладинка книги |
| `PublisherID` | FK → Publisher.PublisherID | Зв’язок із видавництвом |

**Примітка:**
- `PageCount > 0`.  
- `ISBN` унікальний.  
- Одна книга може мати **кількох авторів і кілька жанрів**.

---

### **Author (Автор)**

| Поле | Тип | Опис |
|------|------|------|
| `AuthorID` | PK, SERIAL | Ідентифікатор автора |
| `FullName` | VARCHAR(100) | Повне ім’я |
| `Country` | VARCHAR(50) | Країна |
| `BirthDate` | DATE | Дата народження |
| `DeathDate` | DATE | Дата смерті (опціонально) |
| `PhotoURL` | VARCHAR(255) | Фото автора |
| `Biography` | TEXT | Біографічна інформація |

**Примітка:**
- `DeathDate >= BirthDate`.  
- Фото автора зберігається як **URL-шлях**.  
- Один автор може мати **декілька книг**.

---

### **Publisher (Видавництво)**

| Поле | Тип | Опис |
|------|------|------|
| `PublisherID` | PK, SERIAL | Ідентифікатор видавництва |
| `Name` | VARCHAR(100) | Назва видавництва |
| `Country` | VARCHAR(50) | Країна |
| `Website` | VARCHAR(255) | Сайт |
| `FoundedYear` | INTEGER | Рік заснування |

**Примітка:**
- `FoundedYear` ≥ 1450 і ≤ поточний рік.  
- Одне видавництво може опублікувати багато книг.  

---

### **Genre (Жанр)**

| Поле | Тип | Опис |
|------|------|------|
| `GenreID` | PK, SERIAL | Ідентифікатор жанру |
| `Name` | VARCHAR(50) | Назва жанру |
| `Description` | TEXT | Опис жанру |

**Примітка:**
- `Name` унікальне.  
- Один жанр може належати багатьом книгам.

---

### **Rating (Оцінка)**

| Поле | Тип | Опис |
|------|------|------|
| `RatingID` | PK, SERIAL | Ідентифікатор оцінки |
| `UserID` | FK → Users.UserID | Хто оцінив |
| `BookID` | FK → Book.BookID | Яку книгу оцінили |
| `Score` | DECIMAL(2,1) | Оцінка (1–5) |

**Примітка:**
- `Score` ∈ [1, 5].  
- `UNIQUE (UserID, BookID)` — користувач оцінює кожну книгу лише один раз.  
- Якщо користувач або книга видалені → рейтинг теж видаляється.

---

### **Review (Відгук)**

| Поле | Тип | Опис |
|------|------|------|
| `ReviewID` | PK, SERIAL | Ідентифікатор відгуку |
| `UserID` | FK → Users.UserID | Автор відгуку |
| `BookID` | FK → Book.BookID | Книга, до якої написано відгук |
| `ReviewText` | TEXT | Текст відгуку |
| `ReviewDate` | TIMESTAMP | Дата створення |
| `LastEditDate` | TIMESTAMP | Дата останнього редагування |

**Примітка:**
- `UNIQUE (UserID, BookID)` — один відгук на книгу.  
- Довжина тексту: 10–5000 символів.  
- При зміні тексту автоматично оновлюється `LastEditDate`.

---

### **BookAuthor (зв’язок Книга ↔ Автор)**

| Поле | Тип | Опис |
|------|------|------|
| `BookID` | PK, FK → Book.BookID | Ідентифікатор книги |
| `AuthorID` | PK, FK → Author.AuthorID | Ідентифікатор автора |
| `AuthorOrder` | INTEGER | Порядок співавтора |

**Примітка:** 
- `AuthorOrder > 0`.  
- Один автор може бути співавтором багатьох книг.

---

### **BookGenre (зв’язок Книга ↔ Жанр)**

| Поле | Тип | Опис |
|------|------|------|
| `BookID` | PK, FK → Book.BookID | Ідентифікатор книги |
| `GenreID` | PK, FK → Genre.GenreID | Ідентифікатор жанру |

**Примітка:**
- Книга може належати кільком жанрам.  

---

## **3. Опис зв’язків**

| Зв’язок | Тип | Поля (FK → PK) | Опис |
|----------|------|----------------|------|
| Users → Rating | 1:N | Rating.UserID → Users.UserID | Користувач може мати багато оцінок |
| Users → Review | 1:N | Review.UserID → Users.UserID | Користувач може мати багато відгуків |
| Book → Rating | 1:N | Rating.BookID → Book.BookID | Книга може мати багато оцінок |
| Book → Review | 1:N | Review.BookID → Book.BookID | Книга може мати багато відгуків |
| Book ↔ Author | M:N | BookAuthor.BookID → Book.BookID, BookAuthor.AuthorID → Author.AuthorID | Книги з кількома авторами |
| Book ↔ Genre | M:N | BookGenre.BookID → Book.BookID, BookGenre.GenreID → Genre.GenreID | Книга може належати кільком жанрам |
| Publisher → Book | 1:N (опціональний) | Book.PublisherID → Publisher.PublisherID | Одне видавництво може опублікувати багато книг |
