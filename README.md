## Лабораторна робота №1 — Проєктування бази даних

📎 [Перейти до лабораторної 1](./Lab_1)

**Завдання:**  
Розробити **ER-модель** бази даних для системи оцінювання книг.  
Визначити основні сутності (користувачі, книги, оцінки, коментарі тощо), їх атрибути та зв’язки між ними.  
Побудувати діаграму сутність-зв’язок (ERD) і сформулювати бізнес-правила для кожної таблиці.

## Лабораторна робота №2 — Створення бази даних у PostgreSQL

📎 [Перейти до лабораторної 2](./Lab_2)

**Завдання:**  
На основі ER-моделі з ЛР-1 створити **SQL-скрипт ініціалізації бази даних**.  
Описати таблиці, ключі, зовнішні ключі, обмеження цілісності та типи даних.  
Перевірити правильність створення структури в середовищі PostgreSQL.

## Лабораторна робота №3 — Маніпулювання даними SQL (OLTP)

📎 [Перейти до лабораторної 3](./Lab_3)

**Завдання:**  
Протестувати створену базу даних, виконуючи **операції маніпулювання даними (DML)** у середовищі PostgreSQL.  
Реалізувати типові транзакційні запити у стилі **OLTP** — короткі операції вибірки, вставки, оновлення та видалення окремих записів.

## Лабораторна робота №5 — Нормалізація бази даних

📎 [Перейти до лабораторної 5](./Lab_5)

**Завдання:**  
Проаналізувати створену схему та **виконати нормалізацію** бази даних до **3NF**.  
Виявити надлишковість і аномалії, визначити **функціональні залежності**,  
перевірити таблиці на відповідність **1NF, 2NF і 3NF**,  
а також перебудувати структуру для усунення часткових і транзитивних залежностей.
