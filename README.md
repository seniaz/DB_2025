## 🔹 Лабораторна робота №3 — Маніпулювання даними SQL (OLTP)

📎 [Перейти до лабораторної 3](./Lab_3)

**Завдання:**  
Протестувати створену базу даних, виконуючи **операції маніпулювання даними (DML)** у середовищі PostgreSQL.  
Реалізувати типові транзакційні запити у стилі **OLTP** — короткі операції вибірки, вставки, оновлення та видалення окремих записів.  
Основні вимоги:
- написати запити `SELECT` для отримання та фільтрації даних із таблиць;  
- виконати `INSERT` для додавання нових рядків;  
- реалізувати `UPDATE` для зміни існуючих записів із використанням `WHERE`;  
- застосувати `DELETE` для безпечного видалення даних;  
- перевірити результати кожної операції за допомогою вибірок `SELECT`.  

У звіті подати SQL-скрипт з усіма командами, короткі коментарі до кожної операції, а також підтвердження виконання запитів (наприклад, скріншоти або результати запитів у pgAdmin).
