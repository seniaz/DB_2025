## 🔹 Лабораторна робота №3 — Маніпулювання даними SQL (OLTP)

📎 [Перейти до лабораторної 3](./Lab_3)

**Завдання:**  
Протестувати створену базу даних, виконуючи **операції маніпулювання даними (DML)** у середовищі PostgreSQL.  
Реалізувати типові транзакційні запити у стилі **OLTP** — короткі операції вибірки, вставки, оновлення та видалення окремих записів.  
Основні вимоги:
- написати запити `SELECT` для отримання та фільтрації даних із таблиць;  
- виконати `INSERT` для додавання нових рядків;  
- реалізувати `UPDATE` для зміни існуючих записів із використанням `WHERE`;  
- застосувати `DELETE` для безпечного видалення даних;  
- перевірити результати кожної операції за допомогою вибірок `SELECT`.  

У звіті подати SQL-скрипт з усіма командами, короткі коментарі до кожної операції, а також підтвердження виконання запитів (наприклад, скріншоти або результати запитів у pgAdmin).

## 🔹 Лабораторна робота №4 — Аналітичні SQL-запити (OLAP)
📎 [Перейти до лабораторної 4](./Lab_4)

**Завдання:**  
Реалізувати **аналітичні запити** для підсумовування та аналізу даних у PostgreSQL  
з використанням принципів **OLAP**.  

Основні дії:
- застосувати агрегатні функції `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`;  
- використовувати `GROUP BY` і `HAVING` для групування та фільтрації результатів;  
- реалізувати різні типи `JOIN` для об’єднання таблиць;  
- створити кілька підзапитів для складніших умов.  

Результатом є SQL-скрипти з прикладами запитів і короткими описами до кожного.

## 🔹 Лабораторна робота №5 — Нормалізація бази даних
📎 [Перейти до лабораторної 5](./Lab5)

**Завдання:**  
Проаналізувати створену схему та **виконати нормалізацію** бази даних до **3NF**.  
Виявити надлишковість і аномалії, визначити **функціональні залежності**,  
перевірити таблиці на відповідність **1NF, 2NF і 3NF**,  
а також перебудувати структуру для усунення часткових і транзитивних залежностей.  

Основні дії:
- описати функціональні залежності для кожної таблиці;  
- покроково показати перехід до вищих нормальних форм;  
- створити оновлені `CREATE TABLE`-скрипти для нової структури;  
- побудувати оновлену **ER-діаграму** після нормалізації.
