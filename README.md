## 🔹 Лабораторна робота №1 — Проєктування бази даних

📎 [Перейти до лабораторної 1](./Lab_1)  

**Завдання:**  
Розробити **ER-модель** бази даних для системи оцінювання книг.  
Визначити основні сутності (користувачі, книги, оцінки, коментарі тощо), їх атрибути та зв’язки між ними.  
Побудувати діаграму сутність-зв’язок (ERD) і сформулювати бізнес-правила для кожної таблиці.

---

## 🔹 Лабораторна робота №2 — Створення бази даних у PostgreSQL

📎 [Перейти до лабораторної 2](./Lab_2)  

**Завдання:**  
На основі ER-моделі з ЛР-1 створити **SQL-скрипт ініціалізації бази даних**.  
Описати таблиці, ключі, зовнішні ключі, обмеження цілісності та типи даних.  
Перевірити правильність створення структури в середовищі PostgreSQL.

## 🔹 Лабораторна робота №3 — Автоматизація запуску через Docker

📎 [Перейти до лабораторної 3](./Lab_3)  

**Завдання:**  
Налаштувати **Docker Compose** для автоматичного розгортання бази даних.  
Створити контейнер із PostgreSQL, змонтувати томи для збереження даних і додати скрипти ініціалізації (`init-scripts`).  
Перевірити працездатність за допомогою healthcheck і підключення через клієнт PostgreSQL.
